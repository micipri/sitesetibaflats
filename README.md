# Setiba Flats

Site oficial do Setiba Flats - Hospedagem de frente para o mar em Guarapari, ES.

![Visualização do Site](img/hero-image.jpg) <!-- Exemplo de placeholder se houver imagem relevante -->

## 🏖️ Sobre o Projeto

Este é o site oficial do Setiba Flats, desenvolvido para proporcionar uma experiência de reserva fácil e informativa para nossos hóspedes. O site destaca nossas acomodações, localização privilegiada e as belezas da Praia de Setiba.

## 🚀 Funcionalidades

- **Design Responsivo**: Otimizado para dispositivos móveis, tablets e desktop.
- **Galeria de Fotos**: Fotos em alta qualidade das suítes e da vista.
- **Informações Detalhadas**: Tarifas, comodidades e localização.
- **Contato Direto**: Links integrados para WhatsApp e redes sociais para reservas.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica do site.
- **CSS3**: Estilização moderna e layout responsivo.
- **JavaScript**: Interatividade e animações sutis.

## 📦 Como visualizar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/sitesetibaflats.git
   ```
2. Abra o arquivo `index.html` em seu navegador.
